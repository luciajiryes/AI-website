# Understanding Artificial Intelligence

A simple website explaining AI, its benefits, its challenges and its possible future.

## Files
- `index.html` — website content and structure
- `styles.css` — basic website styling

## Test locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `ai-project`.
2. Upload `index.html` and `styles.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Your website should appear at `https://YOUR-USERNAME.github.io/ai-project/`.

Replace `YOUR-USERNAME` with your GitHub username. Test the published website and all its links before submitting.
